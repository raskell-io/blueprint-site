This site has no server. It is rendered once, when a change is merged, and served as plain files from a CDN. There is
nothing to patch at two in the morning, and nothing that runs your code when a stranger sends a request.

Start with the [articles](@/articles/_index.md), the short [notes](@/notes/_index.md), or the
[projects](@/projects.md). Machines can start at [/llms.txt](/llms.txt).
